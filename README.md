## 👋 About Me

I'm **Agene Sunday Okoh**, a freelance software engineer and fellow of the **Learn2Earn Nigeria (L2E)** programme, Otukpo Campus. I work AI-native: I use AI as leverage to design, build and ship dependable software, with **Go** as my main language and Python, TypeScript, React and Rust alongside it.

I like building tools that people actually use: learning platforms for fellow learners, marketplaces for farmers, and command-line utilities written from scratch. I also hold a B.A. in Philosophy, which is where my habit of breaking problems down before writing code comes from.

```go
package main
```

### 🎨 ASCII Art Engine: Command-Line Rendering Tool *(team project)*

> A CLI and web tool that renders styled ASCII art from text, **built from scratch with no external art libraries.**

![Go](https://img.shields.io/badge/Go-00ADD8?style=flat-square&logo=go&logoColor=white)
![CLI](https://img.shields.io/badge/CLI%20Tool-0C2B22?style=flat-square&logo=gnubash&logoColor=white)
![Tested](https://img.shields.io/badge/Test%20Suite-34D399?style=flat-square&logoColor=06130E)

- 🔤 Renders text with bitmap banner files
- 💾 `--output=<file>` writes results to disk
- 🌈 `--color=<color>` applies ANSI colouring
- 📐 `--align=<type>` aligns output in the terminal
- 🌐 Also served over HTTP with Go's `net/http`
- ✅ Structured as an internal package with tests per function
